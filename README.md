# ReaUninstallerPro - Deep Software Removal & System Cleaner

An open-source uninstaller for Windows designed to thoroughly eliminate stubborn software, leftover registry keys, residual program files, UWP Windows Apps, and browser extensions.

---

## 🚀 Features

- **Deep Uninstall Engine:** Runs native uninstallers followed by recursive registry and filesystem sweeps to clean remnants standard uninstallers leave behind.
- **UWP / Windows Store Apps Manager:** Inspects and removes bloatware and pre-installed Windows applications.
- **System Startup & Service Optimization:** View and disable unnecessary auto-start programs and services to accelerate boot times.
- **Secure File Shredder:** Overwrites and destroys sensitive files beyond recovery using multi-pass wiping algorithms.

---

## ✨ Enhancements & Modifications by @xavierlayne

- **Streamlined User Interface:** Removed unnecessary bloat modules (such as legacy telemetry and security sidebar items) to focus purely on deep uninstallation performance.
- **Clean Visual Theme:** Modern, dark-mode native interface free from third-party advertising or proprietary brand assets.
- **Prominent Attribution:** Built-in badges and links crediting [@xavierlayne](https://github.com/xavierlayne) in titlebars and status dialogs.
- **Standalone Portable Build:** Ready-to-run `.exe` executable generated directly via PyInstaller.

---

## 🛠️ Usage

### Running the Executable
Launch `ReaUninstallerPro.exe` with administrative privileges.

### Running from Source
```bash
git clone https://github.com/xavierlayne/ReaUninstallerPro.git
cd ReaUninstallerPro
python -m pip install -r requirements.txt
python main.py
```

# ReaUninstallerPro

Windows için geliştirilmiş, artık kayıt defteri anahtarlarını, geçici dosyaları, UWP Windows uygulamalarını ve tarayıcı eklentilerini derinlemesine temizleyen açık kaynaklı kaldırma aracı.

## Özellikler
- **Program Kaldırma & Derin Tarama:** Standart kaldırıcıların geride bıraktığı tüm dosya ve kayıt defteri kalıntılarını temizler.
- **UWP / Windows Uygulamaları:** Yerleşik veya sonradan yüklenen Windows mağaza uygulamalarını kaldırır.
- **Yazılım Sağlığı & Başlangıç Yönetimi:** Sistem başlangıcını ve bozuk servisleri optimize eder.
- **Dosya Öğütücü (Shredder):** Hassas dosyaları güvenli ve kalıcı olarak imha eder.
